This thesis investigates the integration of Retrieval-Augmented Generation (RAG) systems into on-premise customized Product Lifecycle Management (PLM) environments to address knowledge accessibility challenges in enterprise documentation management. Manufacturing organizations using PLM systems face persistent difficulties navigating fragmented documentation spanning vendor help files, release notes, and customer-specific standard operating procedures, while strict data governance requirements prohibit cloud-based AI solutions that might risk intellectual property protection.

The research employs Design Science Research methodology combined with a single case study approach to develop, implement, and evaluate a RAG-based AI assistant for Sovelia Core, an on-premise PLM platform widely adopted across Nordic manufacturing enterprises. The implemented system architecture utilizes PostgreSQL with pgvector extension for vector storage, supports multiple LLM providers through abstraction layers enabling flexible deployment strategies, and integrates database-level access control mechanisms maintaining existing PLM permission boundaries. A documentation pipeline processes content from multiple sources (internal PLM documents, vendor documentation via API, web-based knowledge articles) through automated chunking, embedding generation, and version-aware updates.

Evaluation combined expert assessment of response quality with technical performance measurements across two LLM deployment configurations: cloud-based proprietary models (OpenAI GPT-5 Nano) and on-premise open-source alternatives (Ollama GPT-OSS-20B on dedicated GPU infrastructure). Expert evaluation of 30 representative queries spanning five question categories (feature inquiries, procedural questions, troubleshooting, version-specific queries, integration questions) yielded mean scores between 4,31 and 4,49 on a 5-point scale across four dimensions (factual accuracy, relevance, source attribution, completeness), corresponding to quality ratings between Good and Excellent.

Performance testing revealed substantial differences in response times between the tested configurations (25,9 seconds for cloud-based inference versus 91,4 seconds for the Ollama deployment), though this gap likely reflects Ollama's single-GPU architectural constraints and optimization differences rather than fundamental on-premise limitations, as more sophisticated frameworks could substantially improve local performance. Retrieval operations completed consistently under 100 milliseconds regardless of LLM provider. Qualitative analysis identified documentation coverage as the primary constraint on response quality rather than retrieval or generation failures, with evaluators attributing response weaknesses predominantly to missing or incomplete source material, although selecting the most appropriate documentation snippets also influenced perceived relevance and accuracy.

The research contributes theoretical insights demonstrating that documentation quality constitutes the primary determinant of RAG system effectiveness in domain-specific deployments, that hybrid cloud-local architectures offer viable paths balancing data governance constraints with performance requirements, and that simple retrieval approaches (vector similarity with BM25 reranking) perform adequately when documentation coverage is comprehensive. Practical contributions include a production-ready reference implementation suitable for on-premise enterprise environments, operational patterns for multi-source documentation pipeline management, and cost-performance analysis informing deployment decisions (cloud-based inference costs approximately 0,001 USD per query). The findings establish that RAG-based documentation assistance can achieve operationally viable quality in on-premise PLM environments when organizations invest concurrently in both technical infrastructure and source material improvement, providing evidence-based guidance for similar implementations in comparable enterprise contexts.
