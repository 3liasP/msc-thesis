This thesis examines how Retrieval-Augmented Generation (RAG) can be integrated into on-premise, customized Product Lifecycle Management (PLM) environments to improve access to fragmented documentation (vendor manuals, release notes, and customer-specific instructions) under strict data governance constraints.

Using Design Science Research in a single case study, a RAG-based AI assistant was designed, implemented, and evaluated for Sovelia Core, an on-premise PLM platform used in Nordic manufacturing enterprises. The solution stores embeddings in PostgreSQL database using pgvector, supports multiple LLM providers via abstraction layers, and preserves existing PLM permission boundaries through database-level access control. A documentation pipeline ingests content from internal PLM sources, vendor documentation via API, and web-based knowledge articles, and performs automated chunking, embedding, and version-aware updates.

Evaluation combined expert review of answer quality and performance testing in two deployment configurations: cloud-based proprietary inference (OpenAI GPT-5 Nano) and an on-premise open-source deployment (Ollama GPT-OSS-20B on dedicated GPU infrastructure). Experts assessed 30 representative queries across five categories (features, procedures, troubleshooting, version-specific differences, and integrations). Mean scores ranged from 4,31 to 4,49 on a 5-point scale for factual accuracy, relevance, source attribution, and completeness.

Measured end-to-end response time averaged 25,9 seconds in the cloud configuration and 91,4 seconds in the on-premise Ollama configuration, while retrieval itself remained consistently under 100 milliseconds. Qualitative findings indicate that documentation coverage is the main limiting factor for response quality, more than retrieval or generation errors.

The results suggest that (1) documentation quality and maintenance are decisive for domain RAG performance, (2) hybrid cloud-local deployments can balance governance requirements with performance, and (3) simple retrieval (vector similarity with BM25 reranking) is sufficient when source coverage is strong. The thesis delivers a production-ready reference implementation and operational patterns for multi-source documentation pipelines, supported by a cost-performance analysis (cloud inference approximately 0,001 USD per query).
