\section{Evaluation framework}
\label{app:evaluation-framework}

The RAG system evaluation employs a structured assessment framework where expert evaluators rate each response across four dimensions. This framework enables systematic comparison of answer quality and identification of system strengths and weaknesses.

\subsection{Evaluation dimensions}
\label{app:evaluation-dimensions}

Each response is assessed across four key dimensions that capture different aspects of answer quality:

\begin{enumerate}
    \item \textbf{Factual accuracy}: Correctness of information provided in the response
    \item \textbf{Relevance}: Degree to which the response addresses the user's specific information need
    \item \textbf{Source attribution}: Quality and completeness of cited documentation sources
    \item \textbf{Completeness}: Sufficiency of information provided without requiring follow-up queries
\end{enumerate}

\subsection{Rating scale}
\label{app:rating-scale}

All dimensions employ a 5-point Likert scale to provide granular assessment of response quality:

\begin{itemize}
    \item \textbf{5 (Excellent)}: Response fully meets or exceeds expectations for this dimension
    \item \textbf{4 (Good)}: Response meets expectations with minor limitations
    \item \textbf{3 (Acceptable)}: Response is adequate but has noticeable gaps or weaknesses
    \item \textbf{2 (Poor)}: Response has significant deficiencies that impair utility
    \item \textbf{1 (Very poor)}: Response fails to meet basic requirements for this dimension
\end{itemize}

\subsection{Notes for evaluators}
\label{app:evaluation-notes}

The following contextual information guides the evaluation process:

\begin{itemize}
    \item Questions are based on actual Sovelia Core documentation content, specifically Sovelia Help files and release notes from Sovelia.com, ensuring realistic evaluation scenarios
    \item The system provides three source references per response by default, though this limit is configurable in the RAG implementation
    \item The knowledge base includes both vendor documentation (Sovelia Help and release notes) and customer-specific documents, reflecting a typical enterprise deployment
    \item Version-specific questions focus on features introduced or modified in releases 23.0 through 25.1, reflecting the available documentation corpus
    \item Integration questions cover CAD Add-ins (Inventor, SolidWorks), ERP system integration, and Extranet scenarios
    \item Questions represent realistic user information needs identified from actual support inquiries, user documentation sections, and common onboarding challenges observed in practice
\end{itemize}
