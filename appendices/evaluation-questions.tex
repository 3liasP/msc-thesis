\chapter{RAG system evaluation questions}
\label{app:evaluation-questions}

This appendix contains the 30 questions across 5 categories used for evaluating the RAG-based AI assistant integrated with Sovelia Core. These questions are based on actual documentation content available in the system and represent realistic user information needs identified from support inquiries, user documentation sections, and common onboarding challenges.

\section{Feature inquiries}
\label{app:category-feature-inquiries}

Questions about system capabilities, configuration options, and available features.

\textbf{Q1.1}: \textit{What are the available lifecycle states for items in Sovelia Core?}

\textbf{Q1.2}: \textit{How do I configure automatic revision increments for my items?}

\textbf{Q1.3}: \textit{What types of reports are available in the Sovelia Core Template?}

\textbf{Q1.4}: \textit{What is the difference between Product documents and general Documents in Sovelia?}

\textbf{Q1.5}: \textit{What file formats does Sovelia Core support for document conversion to PDF?}

\textbf{Q1.6}: \textit{What user roles are available for managing product data in the Sovelia Template?}

\section{Procedural questions}
\label{app:category-procedural-questions}

Step-by-step instructions for common tasks and workflows.

\textbf{Q2.1}: \textit{How do I release a document for manufacturing in Sovelia Core?}

\textbf{Q2.2}: \textit{What is the process for creating a new item in Sovelia?}

\textbf{Q2.3}: \textit{How do I add components to a bill of materials structure?}

\textbf{Q2.4}: \textit{How can I clone an existing item structure for a new product variant?}

\textbf{Q2.5}: \textit{What steps are required to create an Engineering Change Order (ECO)?}

\textbf{Q2.6}: \textit{How do I export a BOM structure to Excel for external use?}

\section{Troubleshooting queries}
\label{app:category-troubleshooting-queries}

Questions about error messages, unexpected behavior, and problem resolution.

\textbf{Q3.1}: \textit{Why can't I check in my document after making changes?}

\textbf{Q3.2}: \textit{Why does Sovelia prevent me from promoting my item to In Production status?}

\textbf{Q3.3}: \textit{I'm getting a "No permission" message when trying to edit an item. What should I do?}

\textbf{Q3.4}: \textit{Why don't I see the 3D viewer option for my item?}

\textbf{Q3.5}: \textit{My search is taking too long and returning too many results. How can I cancel or refine it?}

\textbf{Q3.6}: \textit{Why are my linked child items not appearing in the structure view?}

\section{Version-specific questions}
\label{app:category-version-specific-questions}

Queries about features introduced in specific releases or changes between versions.

\textbf{Q4.1}: \textit{What's new in Sovelia Core version 25.1?}

\textbf{Q4.2}: \textit{Has the search functionality changed in the latest release?}

\textbf{Q4.3}: \textit{When was the drag and drop functionality introduced?}

\textbf{Q4.4}: \textit{What reporting improvements were made in version 25.1?}

\textbf{Q4.5}: \textit{Which version introduced the commenting feature and how has it evolved?}

\textbf{Q4.6}: \textit{What measure functionality is available in the 3D viewer and when was it added?}

Questions about CAD/ERP integration, data exchange, and cross-system workflows.

\textbf{Q5.3}: \textit{How can I control which items are visible to external users through the Extranet?}

\textbf{Q5.4}: \textit{What is the Equipment BOM and how does it relate to the Engineering BOM?}

\textbf{Q5.5}: \textit{How does Sovelia Sync work with local file editing?}

\textbf{Q5.6}: \textit{Can I create ECOs directly from the Inventor CAD Add-in?}
